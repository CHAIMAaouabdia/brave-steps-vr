# GPhob Therapy

Build a complete modern web application called "G_Phob".

Project Description

G_Phob is an AI-assisted virtual reality exposure therapy platform designed to help children, teenagers, and adults overcome anxiety disorders and specific phobias using gradual exposure therapy combined with gamification.

The application is currently an MVP prototype.

The goal is to simulate every possible feature even if some functionalities are not fully operational.

The UI must look like a production-ready startup.

Language:

French by default, with support for Arabic and English.
